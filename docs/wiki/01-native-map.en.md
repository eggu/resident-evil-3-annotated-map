# Native map and scope

[한국어](README.md) | [English](README.en.md) · [Index](README.en.md)

Annotations overlay the native map. `9` cycles visited → revealed by an area map → all. All reveals unexplored outlines but preserves native floor/story variants. Defaults: English, visited scope, size100%, opacity70%; only Rooms on.

`0` toggles all, `1`–`8` categories, `\` (`₩`) switches language. -/= changes name size and `[` `]` name opacity; hold Shift for icon size and opacity. No RE1 full-screen map or RE2 rank feature.
