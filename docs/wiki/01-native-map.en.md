# Native map and scope

[한국어](README.md) | [English](README.en.md) · [Index](README.en.md)

Annotations overlay the native map. `8` cycles visited → revealed by an area map → all. All reveals unexplored outlines but preserves native floor/story variants. Defaults: Korean, visited scope, size100%, opacity70%; monsters off, other categories on.

`0` toggles all, `1`–`7` categories, `9` language. -/= changes size; hold Shift for opacity. No RE1 full-screen map or RE2 rank feature.
