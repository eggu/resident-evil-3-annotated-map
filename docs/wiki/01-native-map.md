# 원작 지도와 표시 범위

[한국어](README.md) | [English](README.en.md) · [Index](README.md)

게임 자체의 지도에 주석을 겹칩니다. `8`은 방문 → 지역 지도로 공개 → 전체를 순환합니다. 전체는 미방문 윤곽도 공개하지만 층·진행별 원작 방 선택을 없애지 않습니다. 기본은 영어·방문 범위·이름100%·불투명도70%, 방 이름만 켬입니다.

`0`은 주석 전체, `1`–`7`은 분류, `9`는 언어입니다. 이름 크기는 -/=, 불투명도는 Shift와 함께 조절합니다. RE1 전용 전체 화면 지도·RE2 랭크 기능은 없습니다.
